# Proyectos Node.js

Coleccion de laboratorios y una API REST para practicar concurrencia, escalamiento, procesamiento de datos y servicios web con Node.js.

## Proyectos

| Carpeta | Tema |
| --- | --- |
| [workers](./workers/) | Event Loop y Worker Threads |
| [lab-escalamiento-nodos](./lab-escalamiento-nodos/) | Balanceador TCP Round-Robin con tres nodos |
| [lab-memoria-streams](./lab-memoria-streams/) | Streams, procesamiento de CSV y backpressure |
| [lab-cola-prioridad](./lab-cola-prioridad/) | Cola de tareas con prioridades y despacho cooperativo |
| [apirestful](./apirestful/) | API de tarjetas de credito con TypeScript y PostgreSQL |

Cada proyecto contiene su propio README con requisitos e instrucciones para ejecutarlo y probarlo.

## Requisitos generales

- Node.js 20 o superior.
- La API REST requiere PostgreSQL; consulta su README para las opciones de inicio.
